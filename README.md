# Asphalt Driveway Sealing Preparation Guide

A practical homeowner guide to preparing an asphalt driveway before sealcoating, diagnosing alligator cracking, comparing asphalt emulsion and acrylic sealers, and protecting stormwater runoff with FHWA, US EPA, and USGS references.

This is a free, standalone mini-resource published on GitHub Pages:

- Homepage — asphalt driveway sealing readiness and inspection: `https://ahmetalkan.github.io/asphalt-driveway-sealing-prep-guide/`
- Subpage — diagnosing linear cracks vs structural alligator cracking: `https://ahmetalkan.github.io/asphalt-driveway-sealing-prep-guide/crack-filling-before-sealcoat.html`
- Subpage — comparing asphalt emulsion, acrylic, and regulated coal-tar sealers: `https://ahmetalkan.github.io/asphalt-driveway-sealing-prep-guide/emulsion-vs-acrylic-sealers.html`
- Subpage — temperature, humidity, and traffic-curing rules: `https://ahmetalkan.github.io/asphalt-driveway-sealing-prep-guide/weather-window-and-curing.html`

It cites public pages on [drivewaysealinglab.com](https://drivewaysealinglab.com/) and official reference sources listed at the bottom of each page. Nothing here is a substitute for advice from a qualified professional.
